# حضرموت اليمني — منيو وسلة وطلبات واتساب

موقع Next.js عربي يُصدّر إلى ملفات ثابتة في out. يعمل على Vercel بدون قاعدة بيانات أو إعدادات سحابية.

## التشغيل

    npm install
    npm run dev

لإنشاء نسخة النشر ومعاينتها:

    npm run build
    npm start

افتح http://localhost:3000. يتطلب البناء Node.js 24.x. Vercel يستخدم إعداد Other عبر framework: null، ويبني مشروع Next.js ثم يعرض مجلد out حسب vercel.json.

## البيانات والصور

- بيانات المطعم والمنيو الأساسية: lib/restaurant.ts.
- أجور المناطق: lib/delivery-areas.json.
- إعدادات الأسعار والتوفر المنشورة: lib/catalog-defaults.json.
- صور الأطباق: public/images/hadramout. الصور والخطوط ملفات محلية تُنسخ إلى out عند البناء، ولا تحتاج تسجيل دخول أو خدمة صور خارجية.
- السلة تحفظ الأصناف والكميات فقط في localStorage، ولا تُحفظ أسماء الزبائن أو هواتفهم أو عناوينهم.
- مراجعة الطلب تتم داخل المتصفح. رابط واتساب يجهّز الرسالة؛ يجب على الزبون ضغط إرسال في واتساب. فتح الرابط لا يثبت وصول الطلب، ولذلك تبقى السلة محفوظة.

## إعدادات الإدارة المحلية

الرابط /owner. كلمة المرور الحالية الموجودة في OWNER-ACCESS.txt تعمل محليًا وبعد النشر؛ الموقع يتضمن قيمة تحقق PBKDF2 فقط في lib/local-owner-access.json، وليس كلمة المرور الأصلية. لإعادة توليد قيمة التحقق من كلمة المرور الموجودة استخدم npm run setup:owner ثم أعد البناء والنشر.

هذه بوابة إعدادات محلية وليست صلاحيات خادم أو حماية لبيانات سرية. لا توجد قاعدة طلبات أو جلسات إدارة على الخادم. تعديلات الأسعار والتوفر والتوصيل تحفظ في نفس المتصفح فقط، وتظهر في تبويباته. لا تنتقل إلى أجهزة الزوار.

لتعميم التعديلات: من نظرة عامة اضغط تحميل الإعدادات للنشر، واستبدل ملف lib/catalog-defaults.json بالملف الناتج، ثم أعد نشر الموقع. استعادة الإعدادات الأصلية تمسح تعديلات المنيو المحلية فقط وتحافظ على السلة.

## النشر والصور

اتبع VERCEL-SETUP.md. ارفع المشروع كاملًا مع مجلد public؛ ملفات الصور بأسماء لاتينية وحروف صغيرة لتتوافق مع استضافة Linux. لا ترفع .env.local أو OWNER-ACCESS.txt أو .data. هذه الملفات القديمة لا يستخدمها الموقع الحالي. لا يلزم Turso أو OWNER_PASSWORD_HASH أو أي مفاتيح تشغيل.

## الفحص

    npm test

الاختبارات تعمل على مجلد out النهائي، وتتحقق من الصور والخطوط، والسلة بدون API، وصحة رسالة واتساب، وتسجيل دخول الإعدادات المحلية واستمرارها وعزلها عن المتصفحات الأخرى. لا ترسل طلبات حقيقية إلى المطعم.
